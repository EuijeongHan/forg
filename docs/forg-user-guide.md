# forG 사용 안내

> **forG — Grounded Intelligence for Corporate Filings**
> DART 공시를 24시간 감시해서, 중요한 것만 골라 텔레그램으로 보내주는 도구입니다.
> 숫자는 가능한 한 DART 정형 데이터를 그대로 쓰고, AI 요약은 보조로만 씁니다.
> 모든 알림에 **원문 링크**가 붙습니다 — 판단은 항상 원문으로.

---

## 시작하기 (2분)

1. 텔레그램에서 **@forg_alert_bot** 검색 → 대화 시작
2. **/start** 입력
3. 커버하는 종목 등록: **/add 삼성전자** 처럼 하나씩
   - 검색 결과에서 버튼으로 여러 개 선택 → "등록 완료"
   - 등록 수 제한 없음 (DART 알림의 40개 제한 같은 것 없음)

이게 전부입니다. 이후는 자동으로 옵니다.

---

## 자동으로 오는 알림 3종

### 🚨 긴급 — 시장 전체, 등록 종목과 무관
상장폐지 결정·정리매매, 회생절차, 부도, 횡령·배임.
**커버리지 밖 종목이어도 옵니다.** 하루 1건 미만이라 시끄럽지 않습니다.
항상 소리가 나도록 설정돼 있습니다.

### ⚠️ 중요 — 등록한 종목, 즉시
유상·무상증자, CB/BW/EB, 합병·분할, 감자, 자기주식,
**5% 대량보유, 임원·주요주주 매매(내부자), 잠정실적, 손익구조 변동, 배당**,
소송, 거래정지, 최대주주 변경, 감사보고서 등.

감사보고서가 **18시 이후 제출**되면 야간 제출 경고가 붙습니다(올빼미 공시 감지).

### 📄 참고 — 등록한 종목, 매일 18:30 묶음
그 외 전부(정기보고서, IR, 주총 등)를 하루 한 번 목록으로 보냅니다.
**등록 종목의 공시는 하나도 버리지 않습니다** — 급한 것만 즉시, 나머지는 묶음.

---

## 직접 조회하기

| 입력 | 결과 |
|---|---|
| `/today` | 내 등록 종목의 오늘 중요 공시 |
| `/today 유상증자` | 위 결과를 '유상증자'로 좁힘 (이번 조회만, 저장 안 됨) |
| `/market` | 시장 전체 오늘 중요 공시 |
| `/market 감사보고서` | 시장 전체에서 검색어로 좁힘 |
| `/today 어제` | 지난 날짜 보기 — `어제` 또는 `20260810` 형식 |
| `/market 20260810 유상증자` | 날짜 + 검색어 조합도 가능 |
| `/list` | 등록 종목 목록 |
| `/remove 기업명` | 등록 해제 |
| `/help` | 전체 사용법 |

목록에서 공시를 누르면 요약이 뜹니다. 채팅창 왼쪽 아래 **메뉴(/) 버튼**에도
명령이 자동완성으로 떠 있습니다.

---

## 질문하기 (베타)

`/ask` 뒤에 자연어로 물어보면 과거 공시까지 검색해 답합니다.

```
/ask 씨젠 최근 1년 자기주식 공시 찾아줘
/ask 그중 처분 금액이 얼마야?      ← 후속 질문은 30분간 문맥이 이어짐
/ask 초기화                        ← 대화 새로 시작
```

- 답변의 모든 공시에는 DART 원문 링크가 붙습니다
- 숫자는 정형 데이터에서 가져오며, 해석·투자 판단은 하지 않습니다
- 베타라 검색을 놓칠 수 있습니다 — 이상하면 알려주세요

---

## 어디까지 믿어도 되나 (솔직한 기준)

- **정형 수치는 신뢰 대상** — 유상증자·CB 등 주요 유형의 발행금액·전환가 같은
  숫자는 AI가 아니라 DART 정형 API 필드에서 그대로 가져옵니다.
- **AI 요약은 참고용** — 정형 데이터가 없는 공시만 AI가 원문을 요약합니다.
  오류·지연이 있을 수 있습니다.
- **투자 의견은 하지 않습니다** — 호재/악재, 매수/매도 판단은 설계상 출력하지
  않게 되어 있습니다. 사실 전달까지가 이 도구의 역할입니다.
- **판단 전 원문 확인** — 모든 알림 하단의 링크가 DART 원문으로 갑니다.

## 🙏 써보고 이것만 알려주세요

이 도구는 지금 너를 위해 만드는 중이라, 불만이 곧 로드맵이 됩니다.
**봇 채팅창에 `/feedback 내용` 한 줄이면 바로 접수됩니다.**
(예: `/feedback 어제 삼성전자 CB 공시 알림이 안 왔어` — 따로 연락 안 해도 됨)
특히 **1번이 제일 중요합니다.**

1. **놓친 공시** — 알림이 안 왔는데 왔어야 했던 것. 종목·공시명·날짜만 기억해두면 됨
2. **쓸모없는 알림** — "이 유형은 안 와도 된다" 싶은 것
3. **요약이 틀린 것** — 숫자·내용이 원문과 다른 경우 (스크린샷이면 최고)
4. **있었으면 하는 것** — 예: 과거 공시 검색, 정정 전후 비교, 일정 알림 등
