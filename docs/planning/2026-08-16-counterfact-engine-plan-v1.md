# 카운터팩트(CounterFact) — 추천 반박 근거 엔진 기획서 (v1)

- 작성일: 2026-08-16
- 지위: 반대급부 기획. 운영자 지시("애널리스트의 추천을 반박하는 의견 — 매우 논리적으로")에 따른 설계.
- **버전 규칙: 이 파일은 수정하지 않는다. 내용이 바뀌면 `-v2.md`를 새로 만든다.**
- 증거 등급은 적합성 평가 v1과 동일: [A 실증] [B 문서화] [C 문화추론]

---

## 1. 한 줄 정의

애널리스트의 매수 논거를 입력받아, 그 논거와 **상충하는 공시 사실만을** 고정
체크리스트로 조립해 돌려주는 도구.

**의견을 내지 않는다.** "팔아라"가 아니라 — "당신의 논거가 이기려면 설명되어야
할 반대 사실이 여기 7개 있다"를 보여준다.

---

## 2. 왜 이 제품인가 — 반박은 '억제된 정보'다

논리 사슬:

1. [B] 한국 증권사의 매도 리포트 비중은 수년째 **1% 미만**이다(외국계는
   10%대). 금융투자협회 공시 기준으로 언론·국정감사에서 반복 지적된 사실.
2. [B] 원인은 분석 능력이 아니라 **관계 비용**이다. 매도 의견을 낸 애널리스트가
   해당 기업의 IR 접근을 차단당하는 관행이 반복 보도돼 왔다. 법인영업·발행시장
   딜 관계도 같은 방향으로 작용한다.
3. 따라서 반박(bear case)은 시장에서 **구조적으로 생산이 억제된 정보**다.
   수요가 없어서가 아니라, 생산자가 보복당하기 때문에 없다.
4. 기계는 IR에게 미움받을 일도, 법인영업 실적도 없다. **관계 비용이 0인 유일한
   생산자**다. 사람이 인센티브 때문에 못 만드는 정보야말로 AI가 만들 가치가
   가장 큰 정보다.
5. [C] 버사이드가 셀사이드 목표가를 할인해서 읽는 문화 — 반박 자료 수요의
   방증이지만 공개 증거는 없으므로 추론으로 표기.

이 논리의 강점: forG 본체("놓침 방지")와 달리, 카운터팩트는 **인간 대체가 아니라
인간이 구조적으로 비워둔 자리**를 채운다. "AI가 애널리스트만큼 하나?"라는
질문 자체가 성립하지 않는다 — 비교 대상인 인간 생산물이 존재하지 않기 때문이다.

---

## 3. 왜 '의견'이 아니라 '사실 조립'인가

세 가지 제약이 같은 답을 가리킨다.

| 제약 | 귀결 |
|---|---|
| 신뢰 — 엘리트 사용자는 AI의 추론을 신뢰하지 않는다(운영자 전제) | 추론을 팔지 말고 **검증 가능한 사실 + 원문 링크**를 팔아라 |
| 법 — 투자판단 제공 금지(프로젝트 불변 원칙, summarizer 금칙과 동일 계열) | 방향·목표가·확률을 출력하지 않는다 |
| 논리 — **사실의 선택적 제시는 그 자체가 의견이다** | 체크리스트를 **고정·전수**로 만든다. "7개 항목 중 4개 상충 발견, 3개 해당 없음"처럼 커버리지를 항상 명시 → 체리피킹 원천 차단 |

## 4. 체크리스트 v1 — 전 항목 DART만으로 계산 가능

| # | 항목 | 데이터 원천 | 기존 자산 재사용 |
|---|---|---|---|
| 1 | **오버행**: 미전환 CB/BW 잔량, 전환가 vs 현 주가, 전환청구 개시 D-day | cvbdIsDecsn 등 정형 API | raw_typed_data 스냅샷(P1-2), Stage 2 정규화 |
| 2 | **내부자 흐름**: 임원·주요주주 6/12개월 순매도 | 임원ㆍ주요주주특정증권등소유상황보고서 | 신규 (§2.2 커버리지 개편으로 수집 시작) |
| 3 | **5%룰**: 대량보유 감소 추세, 신규 보유자 성격 | 주식등의대량보유상황보고서 | 신규 (동일) |
| 4 | **희석 전력**: 최근 3년 유증·CB·BW 횟수와 규모 | list.json + 정형 API | 축적 중 |
| 5 | **정정 전력**: 공급계약 금액 축소 정정, 정정 빈도 | 기재정정 이력 | **Stage 3 정정 diff 그대로 재사용** |
| 6 | **회계 신호**: 감사의견(한정·거절), 계속기업 강조사항, 감사인 변경 | 감사보고서 | 운영자 직접 테스트 예정 영역 |
| 7 | **법적·거래소**: 소송, 거래정지 이력, 관리종목 지정 | list.json | 등급 알림 규칙 재사용 |
| 8 | **일정 리스크**: 보호예수 해제, 전환청구 개시 등 D-day | 정형 API 일정 필드 | Stage 2 renderer 재사용 |

각 항목의 출력 = **사실값 + 계산식 공개 + 공시 원문 링크**. 셋 중 하나라도
빠지면 출력하지 않는다.

## 5. 입출력

**입력**: 종목 (+ 선택: 매수 논거 bullet)

**출력**:
```
[삼성전자 카운터팩트 — 체크리스트 8항목 전수]
상충 사실 발견 3건 / 해당 없음 5건

② 내부자 흐름   최근 6개월 임원 순매도 4.2만주  [공시 3건 링크]
⑤ 정정 전력     2년 내 공급계약 금액 축소 정정 2건 (−31%, −18%)  [diff 링크]
⑧ 일정          CB 전환청구 개시 D-45, 전환가 52,000원  [공시 링크]

※ 본 자료는 공시 사실의 기계적 대조이며 투자판단·의견이 아닙니다.
```

논거 bullet이 입력되면 항목을 논거에 매핑한다("수주 확대" ↔ ⑤ 정정 전력).

**출력하지 않는 것**: 매도 권고, 목표가, 하락 확률, "위험하다" 류의 평가 형용사.

## 6. 평가 — 이 제품의 최대 강점: 백테스트가 된다

forG 알림의 품질은 측정이 어렵다(놓침은 세기 어렵다). 카운터팩트는 다르다.

- **골든셋 A (사건군)**: 최근 3년 거래정지·상장폐지·급락(−50%) 사례 N=50.
  사건 **이전 시점** 데이터만으로 체크리스트를 돌려, 상충 사실을 몇 개
  보여줬는지 측정 → **재현율**.
- **골든셋 B (대조군)**: 같은 기간 무사고 기업 N=50 → **허경보율**.
- 지표: 사건군 vs 대조군 플래그 수 분포 차이(분별력), 항목별 기여도.
- [A] raw_typed_data 스냅샷을 이미 축적 중 — 데이터 기반이 존재한다.
- 포트폴리오 관점: "측정 가능한 제품" — Track A 평가 하네스(이슈 #4, #8)와
  같은 결. 면접에서 숫자로 말할 수 있는 두 번째 표면.

## 7. 사용 시나리오와 문화 적합

1. **출간 전 셀프 레드팀** — "심의·컴플라이언스에서 나올 질문을 미리 받는다."
   반박 도구가 아니라 **방어 도구**로 프레임한다. "너 틀렸어"를 사줄 애널리스트는
   없지만, "심의 통과를 빠르게"는 산다 [C — 심의 절차 세부는 추론, 인터뷰 검증 필요].
2. **버사이드 수신 검증** — 셀사이드 리포트를 받은 운용역이 30초 카운터팩트로
   반대 사실 유무를 확인.
3. 채널: forG 봇 내 `/counter 종목명` 또는 별도 표면. MVP는 봇 명령이 싸다.

## 8. 리스크와 자기반박

| 반론 | 응답 | 남는 문제 |
|---|---|---|
| "사실 선택도 편향이다" | 고정 전수 체크리스트 + 커버리지 명시 | **항목 설계 자체의 편향**은 남는다. v2에서 항목 근거를 백테스트 기여도로 교체 |
| "DART만으로 업황·수요·기술력 반박은 불가" | 맞다. 범위를 '공시 기반 반박'으로 한정하고 그렇게 표기한다 | 논거의 절반(업황론)에는 침묵하게 됨 — 도구의 정직한 한계 |
| "유사투자자문업 아닌가" | 의견·방향 부재 + 사실·출처만 + 전문가용 | **법률 검토 미완** — legal-review-memo에 안건 추가 필요 |
| "퀀트 스크리너와 뭐가 다른가" | 스크리너는 종목 발굴용 지표 나열. 이것은 특정 논거에 대한 상충 사실 매핑 + 정정 diff·오버행 계산 | 겹침은 있다. 차별점이 실사용에서 체감되는지는 미검증 |
| "애널리스트 자존심에 안 쓴다" [C] | 개인용 프리체크로 침투, 조직 도입은 후순위 | 수요 자체가 추론 — 인터뷰 전까지 투자 최소화 |

## 9. forG와의 관계 및 순서

별도 회사가 아니라 **같은 스택의 두 번째 표면**이다.

- 알림(push) = 놓침 방지 / 카운터팩트(pull) = 판단 방어. 데이터·정규화(Stage 2)·
  정정 diff(Stage 3)·검증(Stage 7) 공유. 한계비용이 낮다.
- 순서 제안:
  1. 등급 알림 개편 (합의됨, 커버리지 결함 수정 — 카운터팩트의 데이터 수집이기도 함: 5%룰·내부자 수집 시작)
  2. Stage 8 질의 축 (pull 검색 — 적합성 평가 §2.4의 갭)
  3. **카운터팩트 MVP**: 체크리스트 4항목(오버행·내부자·5%·정정)만
  4. 골든셋 백테스트 → 항목 확장/폐기 결정
- 즉 지금 당장 새 작업을 벌이지 않아도, 합의된 등급 개편이 이 제품의 1단계를 겸한다.

## 10. v1의 한계

- 시장 수요 미검증(인터뷰 0). §7은 전부 가설이다.
- 항목 가중치 근거 없음 — 백테스트 전까지는 전 항목 동등 취급.
- 법률 검토 미완(§8).
- "반박 의견을 말해달라"는 지시에 대해 이 기획은 **의견 생성을 의도적으로
  거부**했다. 신뢰·법·논리 세 제약의 교집합이 사실 조립이라는 판단인데,
  운영자가 "그래도 의견 형태가 필요하다"고 판단하면 그것은 v2의 논쟁 지점이다.
